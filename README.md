# 📈 股票分析系统

一个基于 Python 的专业股票分析工具，提供技术指标计算、交易信号分析、图表生成和基本面分析功能。支持 A 股市场数据获取和智能联想补全功能。

## 🚀 快速开始

### 🐍 Anaconda 环境运行（推荐）

**1. 创建 Anaconda 环境**
```bash
# 创建名为 stock_analysis 的 Python 3.10 环境
conda create -n stock_analysis python=3.10 -y

# 激活环境
conda activate stock_analysis
```

**2. 安装后端依赖包**
```bash
# 方法一：使用环境配置文件（推荐）
conda env create -f config/environment.yml

# 方法二：手动安装
conda install pandas numpy plotly flask -c conda-forge -y
pip install akshare flask-cors

# 方法三：使用 requirements.txt
pip install -r config/requirements.txt
```

**3. 安装前端依赖包**
```bash
# 进入前端目录
cd frontend

# 安装Node.js依赖
npm install
```

**4. 配置tushare token（可选）**
```bash
# 编辑配置文件
vim config/tushare_token.txt

# 将your_tushare_token_here替换为你的实际token
# 获取地址：https://tushare.pro/register
```

**5. 启动系统**
```bash
# 方法一：一键启动前后端（推荐）
./start_system.sh

# 方法二：简化版启动脚本（如果方法一有问题）
bash start_system_simple.sh

# 方法三：手动启动后端服务（确保在conda环境中）
conda activate stock_analysis
python run.py

# 启动前端服务（新开终端，在项目根目录）
./start_frontend.sh

# 或手动启动前端
cd frontend
npm start
```

**6. 访问应用**
- 前端界面：http://localhost:3000
- 后端API：http://localhost:5000

**5. 在 Anaconda Navigator 中运行**
- 打开 Anaconda Navigator
- 切换到 `stock_analysis` 环境
- 启动 Jupyter Notebook 或 Spyder
- 在 Jupyter 中运行：`%run run.py`

## 📊 使用方法

### 网页界面使用
1. 启动应用：`python run.py`
2. 访问：http://localhost:5000
3. **智能输入股票**：
   - 输入股票代码：`000001`
   - 输入公司名称：`平安银行`
   - 输入拼音缩写：`pab`（平安银行）
   - 输入行业关键词：`银行`、`科技`、`白酒`
4. 点击"生成交易信号"开始多周期分析
5. 查看综合买卖建议和各周期信号概览
6. **使用一级标签页**：点击"交易信号"、"详细分析"、"技术图表"切换不同视图
7. **使用二级标签页**：在每个标签页内，点击周期标签（周线、日线、60分钟等）查看对应周期的数据
8. **展开详细信息**：点击可折叠区域查看技术指标、基本面分析、风险评估等详细内容
9. 查看专业分离式图表：
   - **价格走势图**：K线图 + 移动平均线（MA5/MA10/MA20）+ 布林带
   - **成交量分析图**：独立的成交量柱状图
   - **MACD指标图**：MACD线、信号线、柱状图
   - 支持鼠标拖拽、缩放、十字光标等交互操作
   - 图表时间轴同步显示

### 📊 分离式图表功能

#### 🎯 图表架构
系统采用分离式图表设计，将不同类型的技术指标分别显示在独立的图表面板中，提供更清晰的视觉效果和更好的分析体验。

#### 📈 主要图表面板

**1. 价格走势图（主图表）**
- **K线图**：显示开盘价、收盘价、最高价、最低价
- **移动平均线**：MA5（蓝色）、MA10（橙色）、MA20（紫色）
- **布林带**：上轨、下轨（绿色半透明）
- **图表高度**：400px，提供充足的价格分析空间

**2. 成交量分析图**
- **成交量柱状图**：红绿柱状图，红色表示上涨，绿色表示下跌
- **图表高度**：200px，专注于成交量分析
- **位置**：左下角，与价格图表形成有效对比

**3. MACD指标图**
- **MACD线**：蓝色线条，反映短期与长期均线的差值
- **信号线**：橙色线条，MACD的平滑移动平均
- **柱状图**：红绿柱状图，显示MACD与信号线的差值
- **图表高度**：200px，提供详细的MACD分析
- **位置**：右下角，便于与成交量对比分析

- **家电股**：美的集团、格力电器、苏泊尔等

## 📊 交易信号功能

### 🎯 信号类型

系统基于以下技术指标综合分析生成买卖信号：

- **MACD指标**：金叉/死叉、柱状图变化趋势
- **RSI指标**：超买超卖、趋势方向
- **布林带**：价格位置、突破信号
- **移动平均线**：均线排列、趋势判断
- **成交量**：放量情况、量价配合
- **筹码分布**：价格与压力位、支撑位关系、筹码集中度分析

### 📈 信号强度

- **强烈买入** (≥30)：多个指标显示强烈买入信号
- **买入** (15-29)：指标显示买入信号
- **观望** (-14到14)：信号不明确，建议观望
- **卖出** (-15到-29)：指标显示卖出信号
- **强烈卖出** (≤-30)：多个指标显示强烈卖出信号

### ⚠️ 风险等级

- **高风险**：信号强度≥40，需要严格控制仓位
- **中风险**：信号强度20-39，建议谨慎操作
- **低风险**：信号强度<20，相对安全

### 🔍 详细分析过程

系统提供详细的技术指标分析过程，帮助用户理解每个信号的来源：

#### 📊 MACD分析
- **当前MACD值**：显示MACD线和信号线的具体数值
- **金叉/死叉**：判断MACD线与信号线的交叉情况
- **柱状图趋势**：分析MACD柱状图的变化趋势
- **整体趋势**：多头或空头趋势判断

#### 📈 RSI分析
- **当前RSI值**：显示RSI指标的具体数值
- **超买超卖**：判断是否处于超买(>70)或超卖(<30)区间
- **趋势方向**：RSI的上升或下降趋势
- **位置判断**：强势区(>50)或弱势区(<50)

#### 📊 布林带分析
- **价格位置**：当前价格相对于布林带的位置
- **突破状态**：是否突破上轨或下轨
- **轨道数值**：显示上轨、中轨、下轨的具体价格

#### 📈 移动平均线分析
- **均线数值**：MA5、MA10、MA20的具体价格
- **均线排列**：多头排列、空头排列或混乱排列
- **价格位置**：当前价格相对于20日均线的位置

#### 📊 成交量分析
- **成交量状态**：放量、缩量或正常
- **量比**：当前成交量与平均成交量的比值
- **量价关系**：量价配合或量价背离

#### 💰 筹码分布分析
- **主筹码峰价格**：显示主要筹码集中的价格位置
- **平均价格**：基于筹码分布计算的加权平均价格
- **压力位**：筹码密集区域的上限，可能形成阻力
- **支撑位**：筹码密集区域的下限，可能形成支撑
- **价格位置**：当前价格相对于关键位置的关系
- **筹码集中度**：筹码分布的集中程度百分比
- **集中度状态**：高度集中、正常或分散
- **分析结论**：基于筹码分布的投资建议

### 📋 数据来源

系统显示完整的数据来源信息：
- **数据周期**：日线、60分钟、30分钟、15分钟
- **数据点数**：分析使用的数据条数
- **时间范围**：数据的起止时间
- **计算方法**：各技术指标的具体计算公式，包括筹码分布的计算方法

### 💡 使用建议

1. **综合判断**：不要仅依赖单一信号，要结合多个指标
2. **风险控制**：设置止损位，控制仓位大小
3. **时间周期**：不同时间周期的信号可能有差异，建议结合使用
4. **市场环境**：考虑整体市场环境，避免逆势操作
5. **详细分析**：查看详细分析过程，理解每个信号的判断依据
